# Lab_MVVM — AMFIBIA Studio (в работе)

Панель управления магазином AMFIBIA на шаблоне MVVM (WPF, .NET 10, Visual Studio 2026).
Проект ещё не готов: сделаны данные сайта, шрифты, модели, сервисы и основа MVVM
(ObservableObject, RelayCommand, AsyncRelayCommand, ValidatableObject), ViewModel входа и корневая ViewModel.
